# TypeORM CRUD 실무 가이드: 목차

이 디렉토리는 TypeORM을 활용한 CRUD(생성, 조회, 수정, 삭제) 실전 패턴과 실무 예제를 챕터별로 정리합니다.

- 각 md 파일은 독립적인 챕터로, 실무에서 자주 쓰는 쿼리/패턴/트러블슈팅/베스트 프랙티스를 포함합니다.
- 예제는 실제 엔티티/서비스/컨트롤러/쿼리빌더 등 실전 코드 위주로 작성합니다.

## 목차 예시

- chapter01-basic-crud.md: 기본 CRUD (find, save, update, delete)
- chapter02-where-orderby.md: where, orderBy, 페이징, 동적 쿼리
- chapter03-join-relation.md: join, relation, eager/lazy loading
- chapter04-transaction.md: 트랜잭션 처리
- chapter05-soft-delete.md: 소프트 삭제/복구
- chapter06-raw-query.md: Raw SQL, QueryBuilder 고급 활용
- chapter07-bulk-operation.md: 벌크 insert/update/delete
- chapter08-entity-lifecycle.md: 엔티티 라이프사이클/이벤트
- chapter09-best-practice.md: 실무 베스트 프랙티스/FAQ
