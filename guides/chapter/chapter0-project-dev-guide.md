# 마음사전(가칭) 개발 순서 가이드

## 1. 프로젝트 개요 및 목표 정리

- 서비스 목적, 주요 대상자, 기대 효과, 향후 확장 계획 등 개요서 작성
- 주요 기능 목록 도출 및 우선순위 선정

## 2. 기술 스택 및 프로젝트 구조 설계

- Next.js, TypeScript, PostgreSQL, TypeORM, Tailwind CSS 등 선정
- 폴더 구조 및 주요 모듈(entities, features, lib, shared 등) 설계
- 환경 변수 및 개발/운영 분리 전략 수립

## 3. 초기 세팅 및 기본 환경 구축

- Git 저장소/브랜치 전략 수립
- 패키지 설치 및 tsconfig, eslint, prettier 등 개발 환경 세팅
- Docker, DB 등 인프라 환경 준비

## 4. 데이터베이스 및 엔티티 설계

- 주요 엔티티(예: User, Term, Quiz 등) 설계 및 ERD 작성
- TypeORM 기반 엔티티 코드 작성
- 마이그레이션 및 DB 초기화 스크립트 작성

## 5. 핵심 기능 개발 (1차)

- 용어 검색/조회/상세 설명 API 및 UI
- 시각자료, 발음 듣기, 용어 비교 등 부가 기능 API 및 UI
- 즐겨찾기, 퀴즈 등 학습 기능 구현

## 6. 인증/권한 및 관리자 기능 개발

- 회원가입, 로그인, JWT 인증 등 구현
- 관리자 페이지(용어 추가/수정/삭제, 피드백 관리 등)

## 7. UI/UX 고도화 및 반응형 디자인

- Tailwind, shadcn/ui 등으로 UI 개선
- 모바일/PC 반응형, 접근성, 다크모드 등 적용

## 8. 테스트 및 품질 관리

- 단위/통합 테스트 코드 작성
- ESLint, Prettier, 코드 리뷰 등 품질 관리

## 9. 배포 및 운영 자동화

- Vercel, Docker, CI/CD 등 배포 환경 구축
- 운영/모니터링, 에러 로깅, 백업 등 준비

## 10. 피드백 반영 및 확장 개발

- 사용자 피드백 수집 및 개선
- AI 챗봇, 지역 자원 연계, 영상 콘텐츠 등 확장 기능 개발
