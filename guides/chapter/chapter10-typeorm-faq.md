# 10장: TypeORM 자주 묻는 질문(FAQ)과 문제 해결

이 장에서는 TypeORM을 사용하면서 자주 접하는 질문과 실전 문제 해결법을 정리합니다.

## 10.1. 연결 오류(Connection Error) 발생 시

- DB 주소, 포트, 계정, 방화벽 등 환경 변수 확인
- 커넥션 풀 부족 시 `extra` 옵션으로 풀 크기 조정

## 10.2. 마이그레이션이 적용되지 않을 때

- 엔티티 경로, 마이그레이션 파일 경로, CLI 옵션 확인

## 10.3. Entity 변경이 반영되지 않을 때

- `synchronize: true`로 임시 적용 후, 마이그레이션 권장

## 10.4. 기타 실전 팁

- 공식 문서, GitHub Discussions, Stack Overflow 적극 활용
- 에러 메시지와 로그를 꼼꼼히 확인

---

실무에서 자주 마주치는 문제와 해결법을 빠르게 찾는 방법을 익힙니다.
