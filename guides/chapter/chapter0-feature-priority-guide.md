# 정신건강 용어/퀴즈 사이트 개발 기능 우선순위 및 실무 가이드

이 문서는 정신건강 용어사전 및 퀴즈 웹사이트(예: 마인드렉스) 개발 시 어떤 기능부터 구현할지, 실무적 우선순위와 개발 순서를 안내합니다.

---

## 1. MVP(최소 기능 제품) 핵심 기능 우선순위

### 1) 용어 사전(검색/목록/상세)

- 용어 카테고리별 목록/검색/필터
- 용어 상세 페이지(설명, 시각화, 관련 카테고리 등)
- 용어 데이터 관리(목데이터/DB 연동)

### 2) 퀴즈(기초)

- 랜덤/카테고리별 퀴즈 출제
- 정답/오답 체크 및 해설
- 점수/진행상황 표시

### 3) 회원/인증(소셜 로그인)

- 구글/카카오/네이버 등 소셜 로그인
- 기본 회원 정보 관리

---

## 2. 부가/심화 기능 (MVP 이후 단계)

- 즐겨찾기/북마크(용어, 퀴즈)
- 퀴즈 결과 히스토리/통계
- 관리자(용어/퀴즈 CRUD)
- 사용자 피드백/신고
- 반응형/모바일 최적화, 다크모드
- 접근성(웹 접근성, 폰트/색상 등)
- 커뮤니티/댓글/질문
- 추천 용어/퀴즈/AI 기반 추천

---

## 3. 개발 순서 예시

1. **DB/엔티티/목데이터 설계** (용어, 카테고리, 퀴즈)
2. **REST API/백엔드** (용어/퀴즈 목록, 상세, 검색, 퀴즈 출제)
3. **프론트엔드 UI** (용어 목록/상세, 퀴즈 페이지, 기본 레이아웃)
4. **React Query 등 데이터 패칭/상태 관리**
5. **소셜 로그인/인증**
6. **퀴즈 정답 체크/점수 로직**
7. **반응형/UX 개선**
8. **부가 기능(즐겨찾기, 통계, 관리자 등)**

---

## 4. 실무 팁

- MVP 단계에서는 “용어 사전”과 “퀴즈”의 기본 흐름(검색→상세, 퀴즈→정답체크)부터 완성하세요.
- 인증/회원은 최소 소셜 로그인만 우선 적용해도 충분합니다.
- 데이터/기능이 늘어나면 도메인별 폴더 구조로 리팩토링하세요.
- 목데이터로 빠르게 UI/UX를 검증한 뒤, 실제 DB 연동으로 확장하세요.

---
