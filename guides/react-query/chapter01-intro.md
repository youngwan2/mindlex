# 1장: React Query란 무엇인가?

React Query는 서버 상태 관리, 데이터 패칭, 캐싱, 동기화, 뮤테이션을 위한 React 라이브러리입니다. 클라이언트 상태와 분리된 서버 상태를 효율적으로 관리하며, REST/GraphQL 등 다양한 API와 연동이 쉽고, 캐싱/리페칭/에러/로딩/동기화 등 복잡한 로직을 간결하게 처리할 수 있습니다.

## 주요 특징

- 선언적 데이터 패칭(useQuery, useMutation)
- 자동 캐싱 및 백그라운드 동기화
- 쿼리 무효화/리패칭/프리패칭 지원
- Devtools 제공
- 서버 상태와 클라이언트 상태의 명확한 분리

## 실무 도입 배경

- 전통적 Redux/Context API로 서버 데이터 관리 시 복잡성 증가
- 캐싱/로딩/에러/동기화 등 반복 로직의 중복
- 실시간 UX, 데이터 일관성, 성능 최적화 필요성
