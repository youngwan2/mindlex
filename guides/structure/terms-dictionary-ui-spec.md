# 용어 사전(terms dictionary) 화면 설계서

## 1. 주요 기능 및 구성

- **검색 및 필터링**

  - 키워드(한글/영문/한자/약어/설명 등) 전체 텍스트 검색
  - 트리형 카테고리별 필터(부모/자식)
  - 정렬 옵션(가나다순, 최신순, 인기순 등)

- **목록/카드/테이블 뷰**

  - 카드형/리스트형/테이블형 전환 지원
  - 용어명, 영문명, 카테고리, 한 줄 설명, 대표 아이콘/색상 등 표시

- **상세 페이지/모달**

  - 정의, 한자, 영문, 시각자료(이미지/도식), 연관 용어, 참고 링크 등
  - 관련 용어/카테고리, 연관 퀴즈 등 연결

- **페이징/무한스크롤**

  - 페이지네이션 또는 무한스크롤 지원

- **즐겨찾기/북마크/공유**

  - 로그인 시 내 용어 저장(즐겨찾기)
  - SNS/링크 공유(카카오톡, 네이버, 트위터 등)

- **접근성/UX**

  - 반응형 디자인(모바일/PC)
  - 다크모드 지원
  - 키보드 내비게이션/스크린리더 등 접근성 고려

- **부가 기능**

  - 퀴즈로 연결(해당 용어로 퀴즈 풀기)
  - 관리자/전문가 검증 마크
  - 신규/인기/추천 태그 등 시각적 강조

- **기타**
  - 용어 추가/수정 제안(사용자 피드백)
  - 외부 연동을 위한 REST API 안내(실무 협업 시)

---

## 2. 화면 구조 예시(와이어프레임)

```
┌───────────────────────────────────────────────┐
│ [상단 검색바]  [카테고리 필터] [정렬 옵션]   │
├───────────────────────────────────────────────┤
│ [카드/리스트/테이블 뷰 전환 버튼]           │
├───────────────────────────────────────────────┤
│ [용어 카드/리스트/테이블]                   │
│  - 용어명/영문/카테고리/설명/아이콘/태그 등 │
│  - [상세보기] [즐겨찾기] [공유]              │
├───────────────────────────────────────────────┤
│ [페이지네이션/무한스크롤]                   │
└───────────────────────────────────────────────┘

※ 용어 클릭 시 상세 모달/페이지로 이동
```

---

## 3. 상세 페이지(모달) 예시

- 용어명, 영문, 한자, 약어, 정의, 상세 설명
- 시각자료(이미지/도식/오디오 등)
- 카테고리, 연관 용어, 관련 퀴즈
- 즐겨찾기/공유/피드백 버튼
- 전문가 검증 마크, 신규/인기 태그 등

---

## 4. 실무 적용 팁

- React Query, TypeORM, REST API, 반응형/다크모드, 접근성 등 실무 패턴 적극 활용
- API URL, fetcher, 상태관리, 컴포넌트 구조 등 guides/structure 내 실무 가이드 참고
- 확장성 고려: 용어 추가/수정/삭제, 카테고리 트리, 연관 데이터 등
